# 场景：培训考核（出题）

**问题**：CAN 协议基础与报文解读

---

## 单选题

### 1. 关于 CAN 的“通用性”，下列说法正确的是？

A. CAN 底层和上层都完全通用，所以不同厂商 BMS 的报文可直接互读  
B. CAN 底层完全通用；上层 8 个字节里每个字节代表什么由厂商定义，完全不通用  
C. CAN 底层不通用，上层完全通用  
D. CAN 像 USB 一样，插上总线就能自动看懂对方数据含义  

**答案：B**

**解析**：知识卡明确：CAN 底层“怎么传”完全通用，包括帧格式、ID 优先级仲裁、错误检测、应答机制；但上层“传什么”完全不通用，8 个字节中每个字节代表什么由厂商自己定义。储能/BMS 常见私有协议基本不公开。所以陷阱是：能通信 ≠ 能看懂数据。

---

### 2. 某 CAN 帧 DLC=2，抓包工具数据场显示为 `03 1A 00 00 00 00 00 00`。下列说法正确的是？

A. 有效数据是 8 个字节，因为数据场显示了 8 个字节  
B. 有效数据是 2 个字节 `03 1A`，后 6 个字节是填充值，通常为 0 或 0xAA，不应按有效数据解析  
C. DLC=2 表示 ID 占 2 个字节  
D. 后 6 个字节一定是 SOC  

**答案：B**

**解析**：DLC 是数据长度码。知识卡示例：DLC=2 时有效数据为 2 个字节；当 DLC=2 但数据场写了 8 个字节时，超出有效数据的后 6 个字节是填充值，常见取值是 0 或 0xAA。边界陷阱：抓包工具显示了 8 个字节，不代表 8 个字节都有效，必须看 DLC。

---

### 3. 某温度信号定义：原始值=109，分辨率=0.1，偏移量=-40。按公式“物理量 = 原始值 × 分辨率 + 偏移量”，温度是多少？

A. 10.9℃  
B. 69℃  
C. -29.1℃  
D. 109℃  

**答案：C**

**解析**：109 × 0.1 + (-40) = 10.9 - 40 = -29.1℃。知识卡强调：物理量需要换算公式，偏移量示例可为 0 或 -40；有偏移时结果可能为负。陷阱是只乘分辨率而漏掉负偏移。

## 场景题

你现场用 CAN 抓包，看到一帧周期约 100ms，ID=`0x18F00400`，DLC=8，数据字节为：

`03 1A 00 05 02 00 00 00`

手头有一份 DBC 定义：

- ID `0x18F00400`：字节 0-1 小端 = 电池组总压，分辨率 `0.01V/bit`，偏移 `0`
- 字节 3 = SOC，分辨率 `1%/bit`，偏移 `0`
- 字节 4 bit0-2 = 状态位：`0=待机`，`1=充电`，`2=放电`

请回答：

1. 该帧更可能是数据上报帧还是偶发事件/故障帧？为什么？  
2. 按 DBC 解析，总压原始值、总压、SOC、状态分别是什么？  
3. 如果误按大端读取字节 0-1，会得到什么原始值？说明为什么必须查 DBC/协议文档，而不能仅凭原始字节猜含义。  
4. 若没有 DBC/协议文档，按知识卡给出的反推思路，下一步可以怎么做？

### 参考答案

1. 更可能是数据上报帧/状态帧，因为同一 ID 周期性约 100ms 出现。知识卡指出：数据上报帧通常周期性出现；事件帧、故障帧通常偶尔、不规律出现。

2. 按 DBC：
   - 字节 0-1 为 `03 1A`，小端读作 `0x1A03` = 6659；
   - 总压 = 6659 × 0.01 + 0 = 66.59V；
   - 字节 3 = `0x05` = 5，SOC = 5 × 1% = 5%；
   - 字节 4 = `0x02`，bit0-2 = 2，状态 = 放电。

3. 若误按大端读取字节 0-1：`03 1A` 读作 `0x031A` = 794，与正确的小端值 6659 差异很大。  
   原因：原始报文中看不出起始位、字节序、分辨率、偏移量；同一字节序列在不同厂商协议中可表示完全不同含义。必须依赖 DBC/协议文档才能正确解析。

4. 没有 DBC/协议文档时，可按知识卡反推思路：
   - 第一步找规律：看同一 ID 是否周期性出现，区分数据上报帧与偶发事件/故障帧；
   - 第二步变工况看谁在变：例如充电时哪些字节上升，放电时哪些字节下降，拉高温度时哪些字节缓慢变化，从而定位可能信号；
   - 再结合抓包、试、验证，尝试反推字节序、分辨率、偏移和状态位定义。
